05 FAQ

Questions

Is Blanktick really free?

Yes. No ads, no account, no trial, and no paid version holding back the useful parts. It’s open source.

What do you mean by “bad AI”?

AI that ends up working against you on your own PC: an AI assistant that a web page or email can talk into running commands (prompt injection), AI tools that download and run code, AI model servers anyone on your network can use, and AI keys saved where any program can read them. Blanktick finds these and explains each one. It flags; it doesn’t delete anything, and it can’t catch every possible attack.

Is it an antivirus? Do I still need Windows Security?

Blanktick is the part your antivirus wasn’t built for: the AI on your PC. Live protection catches attacks by what they do, and the check-up finds risky settings. To scan files for viruses — including every file on your PC with Scan whole PC — it uses the engine already built into Windows (Microsoft Defender), so keep Windows Security switched on.

Does Live protection run all the time?

It watches while Blanktick is open. It’s a preview feature: it warns you by default, and stops a flagged program only if you turn that on. Run Blanktick as administrator to let it see the whole PC.

Why does Windows warn me when I install it?

The .msi and .zip aren’t code-signed yet, so Windows shows “Windows protected your PC”. Click More info then Run anyway, and check the download is genuine with the fingerprint in the download section. To skip the warning, get Blanktick from the Microsoft Store instead; Microsoft signs that version.

Does it send my data anywhere?

No. Blanktick makes no internet connection. When it asks Defender to scan a file, Defender may contact Microsoft depending on your own Windows settings.

Mac, iPhone or Android?

Windows only for now. An Android version exists for people who build it themselves; it isn’t on Google Play.
