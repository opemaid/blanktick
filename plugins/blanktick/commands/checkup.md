Use the security-checkup skill. Run `blanktick_scan` (it takes about 100 seconds, so say so first), then report:

1. The score, together with how many checks ran and how many could not.
2. Critical and High findings first, each with its rule id and Blanktick's fix.
3. What could not be checked on this machine, and why.
4. If stored history exists, what changed since the previous scan.

Change nothing on the machine. Recommend; the user decides and acts.
