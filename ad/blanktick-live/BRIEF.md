## Intent

Sequel to "The Tick That Lies". That ad sold the free offline posture scanner.
This one sells the new **live protection** built into the app: a local sensor
that watches process / network / DNS behaviour as it happens and flags
attack behaviour, including AI-driven. Calm and honest, NOT the hacker-neon look.

## Only-true claims (all shipped this session)
- Free offline posture scanner, 85 checks; finds what an antivirus dashboard doesn't.
- NEW live protection (Pro · preview): a LOCAL sensor watches process/network/DNS
  live, fully offline — opens no network; the build fails if networking is added.
- Flags attack behaviour incl. AI-driven: a document spawning a shell; an AI
  assistant driven to run commands; an action right after reading outside content
  (prompt injection); credential theft; ransomware mass-encryption; beaconing; DNS tunnelling.
- With enforcement ON (off by default — the user's choice) it can STOP a flagged process.
- Never phones home; never changes a setting without you; free and open source (AGPL-3.0).

## Forbidden
"removes malware" / "cleans" / "quarantines" (it stops a running process, not files
or persistence); "blocks everything" / "total protection" / "replaces your antivirus";
"antivirus" as what Blanktick IS (it sits beside one); "always on" / "24/7" (runs while
open + Started); any number but "85 checks"; any price but "free"; any URL / store badge /
download button; any competitor.
